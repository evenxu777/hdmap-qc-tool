## 遗留风险

1. **Docker 未实测**：本机无 Docker CLI，`Dockerfile` 与两条 docker 命令未验证；README 已标注。
2. **无 `--strict`，退出码恒为 0**：不能直接作为 CI 硬门禁；若接入需外层脚本读取 `qc_report.json` 的 `issues_total` 再决定失败。
3. **git 不可用**：无法核验仓库跟踪状态与 diff，提交清单只能按文件系统给出。
4. **规则覆盖边界**：R9 不做 from/to 符号一致校验（真实数据 97/135 反向合法）；laneLink 缺失不报错；R5 只校验 `incomingRoad` 存在，是 R9 的子集。
5. **样本代表性**：真实数据只有 10 份 esmini 样例且均 well-formed，“0 误报”只说明这批数据上不误报，不能证明规则完备；R7/R8 只在自建站点样例上验证。
6. **浏览器兼容性**：HTML 已验证单文件离线打开，未做多浏览器矩阵测试。
7. **`docs/site_map.png` 为手工另存副本**：与 `out_site/site_map.png` 当前字节相同，后续重跑预览不会自动更新该副本。
8. **演示素材缺口**：项目内没有界面截图，可展示素材只有 HTML 报告与 `docs/site_map.png`；3 分钟录屏未完成（README 已如实标注）。
